# SubTalk — JW Multilingual Translation Glossary (v1 draft)

**Зорилго:** Монгол → Турк, Япон → Турк хуримын хадмалд Библийн ном, JW нэршил, гэрлэлтийн хэллэгийг тогтмол зөв хэрэглэхэд туслах локал JSON үгийн сан. **Өгөгдлийн сан шаардахгүй.**

## Хавтас дахь файлууд

- `bible_books.json` — 66 Библийн ном; Монгол / Япон / Турк нэр; хуучин хэллэгийн зарим таних alias. 2025 Турк NWT-ийг үндсэн хувилбар болгов.
- `jw_terms.json` — JW болон Библи, судрын нэр томьёо.
- `wedding_terms.json` — хурим, илтгэл, хөтлөгч, гэр бүлийн үг хэллэг.
- `event_names.example.json` — Галхүү, Аканегийн латин нэрийг баталгаажуулах загвар. `approved:false` байгаа нь санаатай.
- `translation_policy.json` — орчуулга хийх, эшлэл таних, хийсвэр зүйл нэмж болохгүй гэсэн дүрэм.
- `sources.json` — нэршлийг шалгахад ашигласан JW.org эх сурвалжийн холбоос.
- `evaluation_cases.json` — 31 синтетик QA сорил: нэр, үгүйсгэл, хамаатан ба JW-ийн ах/эгч, Библийн эшлэл, Япон давхардал.
- `validate.py` — стандарт Python-оор JSON, 66 ном, давхардсан ID болон нэршлийн чанд шалгалт.
- `claude_code_integration.md` — Claude Code-д хэрэгжүүлэх тодорхой заавар.

## Яг яаж ашиглах вэ

1. Энэ хавтсыг SubTalk репогийн `resources/glossary/` дотор байрлуул.
2. Python backend-д `json.load()` ашиглан **эхлүүлэх үед нэг удаа** унш. Видео/аудио тутам файлыг дахин унших шаардлагагүй.
3. Библийн номыг `id` (жишээ `EPH`) дээр тулгуурлан canonical Турк нэрээр хөрвүүл. ASR сонсогдсон нэр, товчлол, хуучин хувилбар нь `*_aliases`-т байна.
4. JW нэршил `priority: always` бол тухайн ойлголт эх сурвалжид гарсан үед тогтмол Турк нэршил ашигла. `context` бол холбогдох утгатай үед л хэрэглэ. Бүх үгийг prompt руу дур мэдэн нэмж болохгүй.
5. `status: review_required` үгсийг хүнээр шалгуулахаас өмнө **хүчээр солиулахгүй**. Зөвхөн санал болгон Claude-д хязгаарлагдмал дамжуул.
6. Script-ийг бодит ярианы оронд орлуулж болохгүй. Библийн эшлэлийн бүтэн текст энд **байхгүй**.
7. `event_names.example.json`-ийн нэрсийг гэр бүлийнхэнтэй зөв бичлэгээр баталгаажуулж, local нууц мэдээллүүдийг репод хэзээ ч бүү commit хий.

## Чухал ялгаа

- **Эфэс / Ефес → Efesliler** (шинэ Турк NWT). `Efesoslular` нь хуучин хувилбарын таних alias.
- **1 Коринт → 1. Korintliler** (шинэ Турк NWT). `1. Korintoslular` нь хуучин хувилбарын таних alias.
- **Дэд хууль → Kanun’un Tekrarı** (бүтэн номын нэр), 2025 index-д `Tekrar` гэж товчилсон байдаг.
- **Ёохан / Иохан → Yuhanna**.
- **ах / эгч** нь тэр бүр JW-ийн `birader / hemşire` биш: ихэвчлэн `ağabey / abla` гэсэн өдөр тутмын утгатай байж болно.
- **аав** гэдэг нь `baba`; Бурхныг илэрхийлэхгүй бол `Tanrı`/`Yehova` болгохыг хоригло.

## Хүний хяналтын хэрэгцээ

Энэ нь *эхний нэршлийн сан* болохоос хуримын бүх агуулгад 100% зөв гэсэн баталгаа биш. JW.org дээр Турк хэлээр бодитоор хэрэглэгдсэн үгсийг `tr_attested` гэж тэмдэглэсэн; тэдгээрийн Монгол/Япон талын утгын таарлыг мөн нөхцөлөөр шалгана. `review_required` нь урьдчилсан зөвлөмж.

Турк хэлтэй, JW нэр томьёо мэддэг хүнээр **гол нэршил, тангараг, Библийн уншлагын хэсгийг** шалгуулахыг зөвлөе. Хуралд ашиглах Библийн эшлэлүүдийг script ирсний дараа тусад нь урьдчилан бэлтгэнэ.

## Эх сурвалжийн хүрээ

`jw.org/tr` 2025 revised NWT, `jw.org/mn` Mongolian Bible book list, `jw.org/ja` Study Bible index, Turkish official JW terminology, Turkish/Japanese JW wedding guidance. Бүтэн эшлэл, нийтлэл, зохиогчийн эрхтэй урт хэсгийг энэ багцад хуулбарлаагүй.
